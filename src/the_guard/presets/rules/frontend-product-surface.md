# Frontend Product Surface

Consume design system → components → pages. Fill gaps at the owning layer instead of copying visual or interaction rules. Business state, data, navigation and presentation each retain their owner. Use the platform's localization mechanism and respect native behavior. Keep implementation diagnostics out of ordinary user flows unless they support a meaningful user decision.
