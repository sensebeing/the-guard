# Changelog

Notable changes are recorded here. Version numbers follow [Semantic Versioning](https://semver.org/).

## 0.1.0

Initial open-source alpha release.

- Repository-owned architecture policies in `AGENTS.md`, with four core rules and a full 14-rule preset.
- Agent-guided core, full, codebase-distilled, and hybrid onboarding, plus a daily development skill.
- Deterministic Python AST and Swift lexical checks, declared module boundaries, exclusive SQL
  ownership, and baseline-aware retired-table ratchets.
- Independent architecture review through local Codex, Claude, or Antigravity CLIs, with
  evidence-backed rebuttals, committed-snapshot review, and patch-bound `GO` receipts.
- Optional Git `pre-push` integration and post-edit hooks that preserve existing setup.
- English and Simplified Chinese guides, a multi-module configuration example, and contributor guidance.
- Python 3.11+ support with zero external runtime dependencies.
